# Security Policy

## Scope

This repository is **public**. Do not put secrets or sensitive internal procedures here.

## Reporting

If you discover a security issue in a **public** skill (e.g. unsafe guidance that could cause harm):

1. Prefer a private vulnerability report to maintainers.
2. Do not open a public issue that includes exploit details until coordinated disclosure is agreed.

If you accidentally committed a secret:

1. Rotate the credential immediately.
2. Contact maintainers; history rewrite may be required.
3. Enable push protection / secret scanning on forks you control.

## Related private assets

Sensitive tooling is **not** in this repository. Org members: see `agent-skills-private`.
